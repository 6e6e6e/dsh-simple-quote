# dsh-simple-quote

给本机 DSH 用的轻量引用插件：在会话里划词，点一下「添加到输入框」，选中文字会以引用块的形式追加到输入框，光标停在分隔线下方。

## 用法

1. 用鼠标在会话正文里选中一段文字（消息、代码块都可以）；
2. 鼠标释放点右侧出现「添加到输入框」（靠近右边缘时翻到左侧）；
3. 点击后输入框得到：

   ```
   「选中的文字」
   ------
   ```

   光标停在 `------` 的下一行，直接输入要补充的内容即可发送。

已有草稿不会被覆盖：引用块会空一行追加到末尾。

## 细节

- 只在会话正文里触发；输入框、侧边栏、设置页里的选择会被忽略；
- 引用内容会**尽量还原成 Markdown**，而不是纯文本：标题、加粗/斜体/删除线、行内代码、带地址的链接、有序/无序/嵌套/任务列表、代码块（含语言与围栏）、引用块、表格；
- 表格有 `<thead>` 时始终用表头作为 Markdown 表头（即使选区只落在 `<tbody>`），选中的正文行作为数据行；没有 `<thead>` 才退回“选中第一行当表头”；
- KaTeX 公式从 TeX 注解还原为 `$...$`，不会把 MathML 与视觉副本拼成两份；
- 多行选择保留换行与缩进；
- 菜单按实际宽高测量定位：出现在鼠标释放点的右侧并垂直居中，靠近屏幕右边缘时自动翻到左侧，始终夹在视口内；长选区不再把菜单甩到远处，也没有箭头；
- 滚动时菜单收起；窗口尺寸变化时按原鼠标位置重新贴边；Shift+方向键调整选区时引用内容会更新；
- 单次引用上限 12000 字符，超出部分以 `…` 截断（被截断的代码块会按原缩进/引用前缀补上收尾围栏，且不会切断 emoji 的代理对）；
- Esc、点击别处、窗口失焦、切换会话时菜单自动消失；
- 使用宿主主题变量，浅色/深色自动跟随；
- 菜单文案跟随 DSH 语言（中文 / English）。

## 已知限制

- 标着 `@路径` 的文件链接在聊天里渲染成按钮，DOM 中没有原始地址，引用后只保留显示文字；
- 本地图片使用 `blob:` 地址，引用时只保留 alt 文本，不写入临时地址；
- 若草稿里已有 `@文件` chip，整体改写草稿会让 chip 退化为纯文本（内容不丢）；
- `table` 没有 `<thead>` 且只选中一行时，仍按“第一行即表头”输出（Markdown 表格必须有表头，没有更好的退路）。

## 结构

| 文件 | 作用 |
| --- | --- |
| `index.js` | Host 半边，空 `apply`（占位行） |
| `client.js` | 构建产物，浏览器实际加载的唯一入口 |
| `lib/quote-text.js` | 纯文本/几何函数（无 DOM，可直接测试） |
| `lib/selection-markdown.js` | 渲染后 DOM → Markdown 的序列化 |
| `lib/client.template.js` | 插件壳、浮层、监听器、插槽注册 |
| `scripts/build-client.mjs` | 把 `lib/` 注入模板生成 `client.js` |
| `test/*.test.mjs` | 纯函数、jsdom DOM、构建产物冒烟测试 |
| `cordis.patch.yml` | 插入插件行 |
| `locale/*.json` | 插件管理页的显示名与描述 |
| `icon.png` | 插件图标 |

`client.js` 是生成文件，不要直接改；改 `lib/` 下的源文件后重新构建。

客户端通过两个插槽协作：`conversation.composer.dock` 里的不可见桥接组件提供当前会话的草稿写入能力，`shell.overlay` 里的浮层负责渲染菜单。草稿写入走 `conversation.input ... setDraft()`，宿主的 `setDraft` 会把选区留在改写后草稿的末尾（`------` 下一行）；随后调用宿主输入 facade 的 `focus()` 恢复这个 Lexical 选区——直接 focus contenteditable 会让光标落到第一个字符前。若编辑器此前从未获得焦点、恢复出的是旧选区，插件会校验 DOM 光标是否位于编辑器最后一个块，否则显式把它移到末尾。

## 开发

```bash
npm install      # 仅安装 jsdom（测试用；运行时无依赖）
npm run build    # 从 lib/ 生成 client.js（npm pack 的 prepack 也会自动执行）
npm test         # node:test：纯函数、jsdom DOM 序列化、构建产物冒烟
```

宿主客户端的模块加载器只接受已注册包名的 `require`，不能直接 import 相对路径的 ES 模块，所以 `lib/` 需要构建期注入成单文件 `client.js`。
